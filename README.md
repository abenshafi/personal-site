# الموقع الشخصي — عبدالله شافي إدريس

موقع من صفحة واحدة بالعربية والإنجليزية، مكتوب بـ HTML وCSS وJavaScript فقط.

## الملفات

| الملف | ما فيه |
|---|---|
| `index.html` | هيكل الصفحة (لا تحتاج تعديله غالبًا) |
| `styles.css` | التصميم |
| `script.js` | تشغيل الموقع واللغتين |
| `content.json` | **كل النصوص بالعربية والإنجليزية + الروابط + مسارات الصور** |
| `posts.json` | منشورات لينكدإن |
| `images/` | ضع صورك هنا |

## تعديل النصوص

افتح `content.json`. فيه ثلاثة أقسام:
- `shared`: الروابط والصور (مشتركة بين اللغتين).
- `ar`: النصوص العربية.
- `en`: النصوص الإنجليزية.

غيّر النص الذي بين علامتي التنصيص `" "` فقط، وانتبه أن تبقى الفواصل `,` والأقواس كما هي.
للتأكد أن الملف سليم بعد التعديل، الصقه في موقع مثل https://jsonlint.com.

## إضافة الصور

1. ارفع الصورة إلى مجلد `images` (مثال: `images/profile.jpg`).
2. في `content.json` اكتب مسارها:
   - الصورة الشخصية: `"profile": "images/profile.jpg"` (يفضّل صورة طولية بنسبة 4:5).
   - صور الأعمال: داخل `"projects"` مثل `"zahrbaba": "images/zahrbaba.jpg"` (يفضّل صورة عرضية).

ما دام المسار فارغًا يظهر مكانها إطار مكتوب عليه "مكان الصورة".

## إضافة البريد الإلكتروني لاحقًا

في `content.json` ← `shared` ← `links` اكتب:
```json
"email": "name@example.com"
```
فيظهر زر البريد تلقائيًا في قسم التواصل.

وبنفس الطريقة يمكنك إضافة رابط قناة زهر بابا في `"zahrbaba": "https://..."` فيظهر زر "زيارة" تحت المشروع.

## إضافة منشور من لينكدإن

1. افتح المنشور على لينكدإن من الكمبيوتر.
2. اضغط على النقاط الثلاث `…` أعلى المنشور ← **Embed this post** (تضمين هذا المنشور).
3. اضغط **Copy code** (نسخ الكود).
4. افتح `posts.json` وأضف المنشور هكذا:

```json
{
  "posts": [
    { "embed": "<iframe src=\"https://www.linkedin.com/embed/feed/update/urn:li:share:1234567890\" height=\"670\" width=\"504\" frameborder=\"0\" allowfullscreen=\"\" title=\"Embedded post\"></iframe>" }
  ]
}
```

**مهم:** الكود المنسوخ فيه علامات تنصيص `"`، ويجب أن تضع قبل كل واحدة منها شرطة مائلة `\` كما في المثال.
**أسهل طريقة:** انسخ الرابط الموجود بعد `src=` فقط وضعه وحده:

```json
{
  "posts": [
    { "embed": "https://www.linkedin.com/embed/feed/update/urn:li:share:1234567890" },
    { "embed": "https://www.linkedin.com/embed/feed/update/urn:li:share:9876543210" }
  ]
}
```

- افصل بين كل منشور والذي بعده بفاصلة `,` (ولا فاصلة بعد آخر منشور).
- ترتيبها في الملف هو ترتيب ظهورها في الموقع.
- ما دامت القائمة فارغة تظهر عبارة "ستُعرض المنشورات هنا قريبًا".

## اللغة

يفتح الموقع بالعربية إذا كانت لغة متصفح الزائر عربية، وبالإنجليزية لغير ذلك. وإذا ضغط الزائر زر التبديل يتذكر الموقع اختياره في زيارته التالية.

## معاينة الموقع على جهازك

فتح `index.html` مباشرة بالنقر المزدوج لن يحمّل المحتوى، لأن المتصفح يمنع قراءة ملفات JSON بهذه الطريقة. إما أن تعاينه بعد نشره على GitHub Pages، أو تشغّل من مجلد الموقع:
```
python3 -m http.server
```
ثم تفتح http://localhost:8000

## النشر مجانًا على GitHub Pages

1. ادخل إلى صفحة المستودع على GitHub.
2. تأكد أن الملفات موجودة في الفرع `main` (إذا كانت في فرع آخر، ادمجه في `main` عبر Pull Request).
3. اضغط **Settings** (الإعدادات) في أعلى صفحة المستودع.
4. من القائمة الجانبية اختر **Pages**.
5. تحت **Build and deployment**، في خانة **Source** اختر **Deploy from a branch**.
6. في خانة **Branch** اختر `main` والمجلد `/ (root)` ثم اضغط **Save**.
7. انتظر دقيقة أو دقيقتين، ثم حدّث الصفحة: سيظهر في الأعلى رابط موقعك، وغالبًا يكون:
   `https://abenshafi.github.io/personal-site/`

ملاحظة: إذا كان المستودع خاصًا (Private) فقد يطلب GitHub اشتراكًا مدفوعًا لتفعيل Pages. اجعله عامًا (Public) من **Settings ← General ← Danger Zone ← Change visibility** ليبقى النشر مجانيًا.

بعد ذلك، أي تعديل تحفظه في الفرع `main` (مثل تعديل `content.json` من موقع GitHub مباشرة بزر القلم ✏️) يظهر على الموقع خلال دقيقة أو دقيقتين.
